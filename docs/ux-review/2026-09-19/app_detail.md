# 덱 상세 화면 정보 설계 검토 (FloaTFT)

근본 원인은 세 가지입니다.
- **출처가 여섯 곳으로 섞여 있습니다.** 한 화면에 metatft, lol.qq, KR, 글로벌 등 서로 다른 여섯 모집단의 숫자가 섞여 있습니다. 그래서 섹션마다 출처를 해명하는 회색 문구가 붙었습니다.
- **같은 수치가 되풀이됩니다.**
- **게임 중에 찾는 정보가 아래로 밀려 있습니다.** 스크린샷끼리 겹치는 구간을 맞춰 재 보니 화면 전체가 약 2,670dp로 3.5화면 분량입니다. 아이템 배분은 1.8화면, 증강은 2.1화면 아래에 있습니다.

지금 화면은 설계 문서 §6.3·§13.3을 그대로 구현한 결과입니다. 그래서 설계 문서도 함께 고쳐야 합니다.

**읽는 법**
- 심각도 높음: 틀린 표기, 거짓말하는 컨트롤, 오해를 부르는 비교, 또는 사용자가 지적한 군더더기의 중심
- 심각도 중간: 쓰는 정보를 찾는 데 스크롤이나 해석이 더 드는 것
- 심각도 낮음: 다듬기
- 스크린샷 좌표는 원본 1080×2400 기준 y(px)입니다. 코드 줄 번호는 main 754d53c 기준입니다.

## 3. 꼭 고칠 것 상위 5개

1. **출처·비교 줄을 본문에서 모두 걷어 내고 ⓘ '데이터 출처' 시트 하나로 모으기** (D1·D8·D2·D15). 본문의 평균 등수는 네 수치 하나만 남깁니다. 사용자가 지적한 핵심이면서, 척도가 다른 숫자를 나란히 놓아 생기는 오해도 함께 없어집니다.
