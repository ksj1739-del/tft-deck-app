## 2. 흐름 재설계 제안

  - 검색 줄을 눌렀을 때의 예시
  - 조건 밖에 남은 덱 수
  - '아이템 고르기' 시트

  - 누르면 "지금 목록 조건으로 게임 위에 띄우기" 시트와 [TFT 열기]가 뜬다.
- 목록 머리는 네 줄로 정리한다:
  - '중국 기준' 구간 줄
  - 검색 줄

  - "덱 12 / 77"
  - 배너는 데이터가 낡았거나 받는 중일 때만 보인다.
- 상세:
  - 머리를 줄인다.
  - 화면 아래에 [덱 코드 복사][게임 위에 띄우기]를 고정한다.
  - 구간 칩은 그 화면에서만 쓴다.
- 도감: 구조는 두고 조작 줄만 줄인다(N18).

### 내 정보 탭 정리 (7묶음 → 3묶음 + 하위 화면)
1. **오버레이** (맨 위)
   - 게임 위에 띄우기 [켜기/끄기]: 목록의 버튼과 같은 상태
   - 언제 보일까요: TFT가 앞에 있을 때만(자동, 추천) / 항상
   - 판이 끝나면 결과 알림 [스위치]
   - 권한 상태: '다른 앱 위에 표시 · 사용 기록 · 알림'을 각각 '허용됨' 또는 '[허용]'으로. 빠진 것에만 버튼
2. **내 전적**
   - "랄라붕#KR1 · KR [변경]"
   - 전적 카드(갱신 아이콘 하나)
   - 지난 게임 로비(데이터가 있을 때만)
3. **데이터**
   - "9/17 기준 · 3시간 전 받음 [지금 갱신]" 한 줄. 덱·도감·아이콘을 한 번에 받는다.
4. **앱 정보** (하위 화면)
   - 덱·도감·아이콘 세부, 원본 상태, 출처, 버전
- 첫 실행에서 빠뜨린 항목이 있으면 탭 맨 위에 그 항목만 한 줄로 보여 준다. 안내창을 다시 띄우지는 않는다.

### 첫 실행 (설치 뒤 한 번만 — 사용자 요구 그대로)
- 안내가 떠 있는 동안 뒤에서 첫 동기화를 시작한다(N3).
- 한 화면에 세 단계를 두고, 진행 상태를 1/3처럼 보여 준다.
  1. **내 전적 연결**
     - 이름#태그와 지역을 받는다.
     - 실제 조회 결과로 완료를 표시한다: "다이아몬드 IV · 랄라붕#KR1". 실패하면 이유를 보여 준다.
     - 성공하면 "다이아+ 구간으로 볼까요?"를 한 번 제안한다.
  2. **게임 위에 띄우기 권한**
     - 버튼 아래에 "목록에서 FloaTFT → 허용 → 뒤로"를 적는다.
     - 돌아오면 자동으로 완료 표시가 된다. 지금도 되는 부분이다.
  3. **TFT를 켜면 자동으로 띄우기 (선택, 추천)**
     - 비용을 한 줄로 밝힌다.
     - 사용 기록 설정 → 돌아오면 감지가 켜진다.
     - 이어서 이유 한 줄("판 결과, 닫은 창 다시 띄우기")과 함께 알림 권한을 묻는다.
- 버튼은 [나중에] / [완료]. 뒤로 가기는 '나중에'와 같게 처리하고, 닫을 때 "내 정보에서 언제든" 스낵바를 띄운다.
- 판정 요약:
  - 사용 기록 권한은 넣어야 한다. 단, 선택 단계로.
  - 알림 권한은 따로 단계를 두지 않는다. 3단계 끝에 이유와 함께 묻는다.
