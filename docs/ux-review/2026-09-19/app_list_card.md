# FloaTFT 덱 목록·카드 UI/UX 검토

코드는 main 754d53c 를 읽기만 했고, 파일 수정이나 에뮬레이터는 쓰지 않았습니다. 수치는 동봉 데이터(`decks.json`, 2026-09-19 생성)의 골드~에메랄드 구간 기준입니다. 이 구간에는 덱이 70개 있고, 기본 조건(S·A·B)을 걸면 56장이 보입니다. 스크린샷 좌표는 원본 픽셀이고 2.625px 가 1dp 입니다.

**지금 상태:** 카드 한 장이 314dp, 첫 카드 위 영역이 309dp 입니다. 그래서 첫 화면에 카드가 1.4장, 스크롤한 뒤에도 2.1장밖에 안 보입니다.

코드 위치는 모두 `C:\claude_project\tft_deck_app\android\app\src\main\java\com\tftdeck\reader\` 아래입니다. 주로 본 파일은 `ui\components\DeckCardV2.kt`, `StatChips.kt`, `Components.kt`, `ui\screens\DeckListScreen.kt`, `ui\theme\Theme.kt`, `MainActivity.kt`, `data\Models.kt`, `data\DeckSearch.kt`, `overlay\OverlayContent.kt` 입니다. 기준 문서는 `C:\claude_project\tft_deck_app\design-system\floatft\MASTER.md` 와 `C:\claude_project\tft_deck_app\docs\benchmark\2026-09-15\design.md` 입니다.

  - 절반 S·절반 A 등급과 '중국 한정' 표시 자체는 확정된 결정이므로 그대로 둡니다.

### L15 · 등급 배지와 글자 위계가 약하다 — 낮음 · S
- **근거**
  - 배지가 16% 옅은 채움에 11.5sp 글자입니다. MASTER §2 는 "채움 + 어두운 글자"를 정했습니다.

- **고칠 방법:** 배지를 24dp 정사각형 채움으로 바꾸고 어두운 글자 14sp Bold 로 씁니다. 별칭은 16sp 로 키우고, 수치를 첫 줄로 올립니다.

### L16 · 빈 상태·로딩 — 낮음 · S
- **근거:** 로딩 때는 가운데 스피너만 돕니다(DeckListScreen.kt:73-75, 88-91). 빈 상태는 일반 문장뿐이고 버튼이 없습니다(DeckListScreen.kt:119-130). 오버레이는 이미 "C·D 등급이 꺼져 있어 덱 N개가 가려졌습니다"처럼 무엇이 막았는지 알려 줍니다(OverlayListFilter.kt:32-39).
