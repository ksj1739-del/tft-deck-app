## 2. 전역 규칙 제안 (MASTER.md에 넣을 문장)

- **R1 [§3 교체]** 글자 크기는 11 · 12 · 14 · 16 · 20 · 28sp 여섯 단계만 쓴다.
  - 11sp는 배지·칩·수치 라벨처럼 1~3단어에만 쓰고, 문장에는 12sp 이상을 쓴다.
  - 화면 코드에 `.sp` 리터럴을 쓰지 않는다. 오버레이는 `OverlayType` 객체 한 곳에서만 크기를 정한다.
- **R2 [신규]** 보조 글자(onSurfaceVariant)는 카드나 섹션 하나에 한 줄까지 쓴다.
  - 표본·출처·기간은 카드에 쓰지 않는다. 상세의 '데이터 기준' 한 줄과 (i) 시트에만 둔다.
- **R3 [§2 강화]** 색은 한 가지 뜻만 가진다.
  - primary: 누를 수 있음 / 선택됨.
  - onSurface: 제목.
  - Positive/Negative: 좋음/나쁨(▲▼ 병기).
  - Gold: 1등과 3성.
  - 등급 5색: 등급 배지 채움에만.
  - 섹션 제목에 primary를 쓰지 않고, 서로 다른 토큰에 같은 hex를 쓰지 않는다.
- **R4 [§4 강제]** 모서리는 6(배지) · 8(칩) · 12(카드·입력칸) · 16(다이얼로그·시트) · 완전 원(버튼·세그먼트·토큰 칩) 다섯 값만 쓴다. 아이콘은 16/20/24dp, Filled 한 계열만 쓴다.
- **R5 [신규]** 배지는 한 모양이다: 높이 20dp, 모서리 6dp, 가로 안쪽 6dp, 11sp SemiBold.
  - 등급 배지 = 등급색 채움 + background 글자.
  - 그 밖의 배지 = surfaceVariant 채움 + onSurfaceVariant 글자.
  - 테두리만 있는 배지는 편집 등급 하나뿐이다.
- **R6 [§6 교체]** 선택 표시는 한 가지다: secondaryContainer 채움 + onSecondaryContainer 글자 + 테두리 없음.
  - 비선택 칩 = surfaceVariant 채움, 테두리 없음.
  - 꺼짐을 가로줄로 표시하지 않는다.
- **R7 [신규]** 숫자는 이렇게 적는다.
  - 비율: 소수 1자리. 0.1% 미만은 `<0.1%`.
  - 평균 등수: 소수 2자리. 라벨 칸 안에서는 숫자만, 문장 안에서는 `4.12등`.
  - 판 수: 1만 미만 `9,847판`, 1만~100만 미만 `58.5만 판`(소수 1자리 고정), 100만 이상 `108만 판`.
  - 빼기 기호는 U+2212(`−`). `n=`은 쓰지 않는다.
- **R8 [신규]** 용어는 하나씩만 쓴다.

  | 쓴다 | 쓰지 않는다 |
  |---|---|
  | 챔피언 | 유닛 |
  | 특성 | 시너지 |
  | 증강 | 증강체 |
  | 레벨 | 렙, Lv (좁은 칸은 머리에 '레벨' 라벨 + 숫자만) |
  | 순방 (처음 한 번은 '4등 안' 설명) | TOP4, 톱4 |
  | 플래+ / 다이아+ / 마스터+ | 플래티넘+ |
  | 한국 / 중국 / 글로벌 (KR은 서버 선택에서만) | KR 플래+ 같은 표기 |
  | 패치 `18.2` | 18.2b, 16.18, TFTSet18, s18 |
  | 새로고침 | 갱신, 다시 조회, 지금 받기 |

  - 출처 이름(metatft, lol.qq)은 '출처' 시트에만 쓴다.
- **R9 [§4 강제]** 화면 좌우 여백은 16dp다. 간격은 4 · 8 · 12 · 16 · 24dp만 쓴다.
  - 카드 사이 8, 섹션 사이 24, 섹션 제목과 내용 사이 8. 홀수 dp는 쓰지 않는다.
- **R10 [신규]** 한국어 줄바꿈은 어절 단위로 한다(모든 TextStyle에 WordBreak.Phrase).
  - 한 줄 설명은 마침표 없이 쓰고, 두 문장 이상일 때만 마침표를 찍는다.
  - 가운뎃점은 한 줄에 둘까지. 말줄임은 `…` 하나. 앱 어조는 '~합니다'로 통일한다.

## 3. 꼭 고칠 것 상위 5개

1. **정보 다이어트 (V1 · V2 · V3).** 카드의 표본 줄과 KR 배지 줄, 상세의 회색 메타 3줄과 긴 이름 줄을 지우고, 요약과 운영 칩의 중복을 없앱니다. 사용자가 직접 지적한 문제이고, 코드는 지우는 쪽이 대부분입니다.
2. **배지·칩·선택 표시를 한 벌로 (V5 · V6 · V7 · V18).** 등급 배지는 채움형 하나로, 비선택 칩은 테두리 없는 채움으로, 선택은 secondaryContainer 하나로 합칩니다. 첫 화면에서 "덜 다듬어졌다"는 인상을 가장 크게 만드는 부분입니다.
3. **글자 6단계 + sp 리터럴 제거 + 어절 줄바꿈 (V4 · V15).** Theme 정의만 바꿔도 앱 전체에 퍼집니다.
4. **색의 뜻 정리 (V8 · V9 · V10).** 파랑은 누르는 것에만 쓰고, 섹션 제목은 onSurface로 바꿉니다. 카드 면을 #171A20으로 바꾸고, 등급과 좋고 나쁨이 같은 hex를 쓰지 않게 하고, KR 청록을 없앱니다.
5. **숫자·용어 표기 통일 (V11 · V12).** TOP4/톱4, 렙/레벨/Lv, `n=`, 0.04%와 5.6%, 패치 번호 네 가지를 R7과 R8로 한꺼번에 치환합니다.
