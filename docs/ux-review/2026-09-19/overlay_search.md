**꼭 고칠 것 상위 3개**
1. **검색 끝내기 경로 (Q1+Q2, S):** IME 가 숨으면 endSearch 하고, 편집 중 '완료' 버튼을 둔다. 포커스가 남는 경로를 닫고, 게임 오조작 없이 빠져나오게 한다.
2. **가로 후보 칸 (Q3, M):** 후보 목록 높이를 키보드 위 칸에 맞추고, 편집 중에는 칩을 한 줄로·등급 칸을 숨긴다. API 29 이하는 y=0 으로 올린다.
3. **후보 선택과 수 (Q5+Q4, S):** 검색 키는 덱이 있는 색인 후보만 고르게 하고, 0 후보에는 '꺼진 등급 N'을 보인다.

**이미 잘 된 점**
- 창 플래그를 한 곳에서 합성하고, endSearch 를 반복 호출해도 안전하게 만들었다. 12곳에서 부르며, 뒤로를 IME 보다 먼저 받는다. 바깥 누름·뒤로·접기에서 포커스가 풀리는 것을 dumpsys 로 확인했다(a6, a11, a13). 바깥 누름이 게임으로 통과하는 것도 a8, a10 으로 확인됐다.
- 키보드 위치를 화면 기준으로 재어 창을 올리고, 낮은 화면에서 머리줄을 접었다. l1 에서는 후보가 전부 가려졌는데 l13 에서는 검색창과 후보가 보인다.
- 후보마다 축 이름과 남는 덱 수를 보이고 0 이면 흐리게 한다. 빈 목록 안내는 등급 때문인지 짚는다(g10). 등급 칸은 색·채움·가로줄 세 겹으로 켜짐을 구분한다.
